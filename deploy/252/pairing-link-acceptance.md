# 配对链接生命周期修复验收

2026-09-16，正式入口 https://aio.addzero.site。

问题来自授权完成后地址栏仍保留 `worker_pair`。配对码是十分钟内可用的一次性入口，授权后数据库清空该码；刷新旧 URL 会重新请求这个失效入口，旧界面直接展示 HTTP 400，造成设备授权过期的误解。设备身份校验只检查 active 状态及账号有效性，不使用初始配对截止时间。

修复在授权成功、关闭配对和确认入口已失效时，用 History API 移除 `worker_pair`，保留其他查询参数、锚点和 history.state，并同步清除组件状态。旧入口给出说明，不影响已有设备。未确认的新配对刷新仍可继续；临时网络错误、设备数量上限等不会消耗有效入口。
