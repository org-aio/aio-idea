# AIO 多设备个人配置实施计划

目标：同一 AIO 账号的 MacBook Pro、Mac mini 和服务器使用同一份个人配置库，支持双向同步、配置融合、设备差异、环境变量、应用命令和个人安装包。数据以租户＋账号隔离，设备沿用现有配对和长期出站通道。

## 已定边界

- 配对和设备凭据继续由宿主管理，个人配置是独立领域，不依赖智能体或模型调用。Agent 后续可消费这些能力，但日常同步不消耗模型 token。
- 共享配置、操作系统覆盖、指定设备覆盖分别保存，优先级从低到高。文件中的用户主目录使用可移植占位符，避免复制另一台机器的绝对路径。
- 环境变量逐项管理，PATH 管理附加目录；应用启动命令按平台生成，例如 doubao 在 macOS 使用已核实的应用 bundle ID。
- 文本使用三方合并；JSON/JSONC 额外按键合并并保留本地注释。无法确定的同处修改保留冲突，不能按更新时间静默覆盖。每次落盘前备份，云端保存版本。
- 初始导入以 chezmoi 当前已管理且实际存在的文本配置为候选，不运行 chezmoi 脚本，不覆盖其源仓库。已有 AIO Skill 目录不重复管理；缓存、安装包、私钥和会话凭据不混入自动配置扫描。
- 安装包和杂物复用现有 restic 加密归档，增加个人资源目录和跨设备恢复入口。下载或恢复不会自动执行安装程序。
- 新设备配对后需启用配置同步；文件监听与服务器变更通知驱动同步，断网期间保留基线，重连后重新对账。当前终端进程不会被外部程序直接修改环境，新终端加载或显式刷新环境后生效。

## 实施顺序和验收

1. 修复当前 Mac 的 doubao 命令，验证新 zsh 会话及真实应用进程。
2. 新增个人配置领域：加密存储、CAS 版本、分层作用域、设备状态、冲突和归档资源目录。验证同租户不同用户、跨租户、撤权设备均无法越权。
3. 扩展现有 worker：chezmoi 导入、文件监听、三方合并、备份、环境变量和应用命令生成、离线恢复。使用两套独立设备状态模拟 MacBook 与 Mac mini，验证双向修改、自动合并、冲突和设备覆盖。
4. AIO 个人配置界面：配置/环境变量/命令/资源及同步设备，新增编辑使用弹窗，冲突处理和版本恢复可审阅。验收桌面与手机布局、核心操作和控制台。
5. 发布宿主并升级本机 worker，导入批准范围；验证实际 AIO 数据、当前 Mac 配置与同步状态。第二台实体 Mac 尚未接入时明确报告，不把模拟设备测试当作实体 Mac mini 验收。

## 交付证据

源码测试、独立 PostgreSQL 权限与并发测试、双设备故障测试、浏览器截图、正式发布与真实本机验证分别记录；npm/市场分发状态单独报告。所有本次修改提交并推送，保留其他任务已有修改。
